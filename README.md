# Rohan Alam Portfolio (HTML + CSS + JavaScript)

## Files
- `index.html` — website structure and project cards
- `style.css` — responsive styling and Liquid Glass theme
- `script.js` — animations and interactions
- `assets/images/` — add your own project screenshots here
- `assets/videos/` — optional local video files

## Add project screenshots
The project preview areas are ready for your own images. Save each screenshot with the exact filename below and place it in `assets/images/`: 

- `zentris-homepage.png` — Zentris corporate homepage screenshot
- `zentris-erp-dashboard.png` — Zentris ERP screenshot
- `smart-store-management.png` — Smart Store app screenshot
- `image-editor-pro.png` — Image Editor Pro screenshot
- `resumeforge.png` — ResumeForge screenshot
- `aandre-label-design-1.jpg` — first label design
- `aandre-packaging-design-2.jpg` — second packaging design
- `flipkart-product-listing.png` — Flipkart listing screenshot
- `meesho-product-listing.png` — Meesho listing screenshot
- `amazon-product-listing.png` — Amazon listing screenshot

You can use JPG, PNG, or WebP, but if you change an extension, update the matching image `src` in `index.html`. Until you add a screenshot, the card displays an instruction in the preview area rather than an icon. The Instagram Reel remains embedded in its own video card.

## Preview
Open `index.html` in a browser. Internet is required for CDN-hosted libraries and Instagram embeds.

## GitHub Pages
